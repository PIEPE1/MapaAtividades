⚠️ Erro de CORS?

Se receber "Erro de CORS" ou "NetworkError":

  1. Ative a opção acima: "Usar API do GitHub"
  2. Verifique se a URL é correta (copie do botão "Raw" do Gist)
  3. Para Gist secreto, adicione o token
  4. Tente recarregar a página
